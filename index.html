Activity Monitor POC

This page monitors user activity in the partner iframe below. Try clicking, typing, scrolling, or moving your mouse inside the iframe.

How This Works

Parent Page (this page): Uses fake-usage-meter.js to listen for messages from the iframe and tracks user activity. When activity is detected, the header turns green (ACTIVE). After 10 seconds with no activity, it turns gray (INACTIVE).

Partner Iframe: Loads messages-from-iframe.js from this platform to detect user events (click, keydown, scroll, mousemove, visibilitychange) and sends them to the platform page using window.parent.postMessage().
